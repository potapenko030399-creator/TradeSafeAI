# SellCar

Демо автомобильного маркетплейса в стиле макета SellCar из концепта.

## Что реализовано
- Главная лента и поиск
- Категории автомобилей
- Результаты поиска
- Карточка автомобиля
- Избранное
- Сообщения
- Размещение объявления
- Фильтры
- Профиль
- Адаптивный мобильный интерфейс
- Нижняя навигация и интерактивные переходы

## Запуск
Откройте `index.html` в браузере. Проект не требует npm или сторонних библиотек.

## Важно
Интерфейс и бренд SellCar — самостоятельная концепция. Не используются логотипы, фирменные тексты или защищённые визуальные материалы сторонних маркетплейсов.
